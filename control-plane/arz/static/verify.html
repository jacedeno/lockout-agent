Verify a receipt

Every run produces receipt.zip: the hash-chained log of what happened, every file the job produced, and a manifest signed with the control plane's Ed25519 key. Drop one here to check the signature, the signer, the chain and every file hash. Change one byte in any of them and it fails.

Offline, without this site: arz-receipt verify receipt.zip --pubkey $(curl -s https://agentrush.geekendzone.net/.well-known/receipt-key)
