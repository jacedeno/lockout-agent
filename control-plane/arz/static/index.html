An agent that writes its own analysis code, and can't hurt anything when it does.

Pick a measurement and run it. The agent plans, writes Python against vibkit, and runs it in a throwaway Vultr VM with no network and no credentials, inside a locked container. The control plane recomputes the answer itself, rejects any claim the numbers don't support, drafts the work order, destroys the VM, proves it is gone, and signs a receipt of every step.

Every run ends with a lockout tag: isolated, zero energy verified, answer checked, signed.
